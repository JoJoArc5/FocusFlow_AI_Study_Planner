FOCUSFLOW — AI STUDY PLANNER
Front-End Design Project

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. No installation, server, or internet connection is required after the files are downloaded.

FEATURES
- Responsive dashboard
- Add study tasks, choose a subject and priority, and mark tasks complete
- Focus timer with 25-minute focus, 5-minute short break, and 15-minute long break modes
- Subject progress tracking with editable percentages
- Daily focus goal with quick-add minute controls
- Weekly focus chart based on saved timer minutes
- Rule-based study suggestions
- Browser localStorage persistence for tasks, goals, progress, and focus history

AI CLAIMS / LIMITATIONS
The “FocusFlow Coach” is explicitly a SIMULATED AI feature. It generates suggestions locally using simple JavaScript rules based on pending tasks and focus minutes. It does not call an AI model, external API, or cloud service. Real AI integration would require an AI provider/API, a secure backend to protect API credentials, and appropriate privacy handling. Do not put secret API keys in front-end JavaScript.

DATA / PRIVACY
Data is stored in localStorage in the current browser on the current device. Clearing browser site data may erase it. This is a front-end demonstration and is not a cloud-synced product.

TECHNOLOGIES
HTML5, CSS3, vanilla JavaScript.
